# DokanBhai React — No Vite

This version does NOT use Vite, npm, or node_modules.

## Run

Simply double-click:

    index.html

It will open in your browser.

## Important

React is loaded from CDN:
- React 18
- ReactDOM 18
- Babel Standalone

Internet is required for the React/Babel CDN and Google Fonts.

If you want a completely offline version, React can also be downloaded locally.
