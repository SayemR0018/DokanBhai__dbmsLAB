DokanBhai React registration page - No Vite

Files:
- index.html
- styles.css
- app.jsx

How to run:
1. Keep all files in the same folder.
2. Open index.html in a browser.

This version uses React 18 + ReactDOM + Babel from CDN, so no npm/Vite setup is required.
Internet access is needed for React/Babel CDN and Google Fonts.
